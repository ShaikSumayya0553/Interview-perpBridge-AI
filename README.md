# Interview PrepBridge AI - Executive Technical Interview Preparation Platform

Interview PrepBridge AI is a production-grade web application designed to empower software engineers to prepare for technical interviews, track job applications, master DSA problems, and practice mock AI interviews.

---

## 🏗️ Project Architecture (Monorepo Setup)

- **frontend/**: React.js SPA powered by Vite, Tailwind CSS, React Router DOM, Axios, and Lucide React.
- **backend/**: Node.js & Express.js REST API with JWT Auth, Mongoose ODM, and Modular AI Service (Gemini API integration).

---

## 🚀 Quick Start (Local Development)

### 1. Backend Setup
```bash
cd backend
npm install
npm run dev
```
Backend runs on `http://localhost:5000`

### 2. Frontend Setup
```bash
cd frontend
npm install
npm run dev
```
Frontend runs on `http://localhost:5173`
